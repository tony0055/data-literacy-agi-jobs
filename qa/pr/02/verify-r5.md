## 3. 17·24장 교차 PR 주장 — 사실

- `src/charts.js` 216행: `const dd = host.dataset.h ? { ...d, H: Number(host.dataset.h) } : d;`
  - `yearline`(58행)·`capfan`(151행)은 `H = d.H ?? …`이다. `svgOf(W, H)`가 viewBox `0 0 W H`를 만든다.
  - 축·선 좌표도 H로 계산한다(`yBase = H - 72/64`).
- `deck.css` 127행: `.chart svg { width: 100%; height: auto }`.
  - 표시 높이 = 표시 폭 × H/W다.
  - k = 표시 폭 / W = 1이면(실측 17장 960/960, 24장 1552/1552) 표시 높이는 정확히 data-h다(실측 420·400).
- PR2 CSS로 높이를 바꾸는 길은 둘뿐이다.
  - 폭을 키운다: k≠1이 되어 차트 글자 20px 기준이 깨진다.
  - svg에 높이를 따로 준다: preserveAspectRatio meet 때문에 그림은 그대로이고 위아래에 빈 띠만 생긴다. 속 빈 채움이다.
  - 24장 본문은 차트와 출처 문단뿐이라 다른 내용이 없다.
  - 17장 옆 시트 글(끝 505)은 차트 칸(끝 768)보다 이미 짧다. 그래서 끝을 내릴 수 없다.

- `data-h`는 `data-chart` div의 속성이고, PR2 범위에서 제외된 영역(「data-chart 속성 변경 0」)이다. **PR3 소유로 인정한다. PR7에서 data-h를 조정한다.**
