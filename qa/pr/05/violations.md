# PR5 배정 위반 처리표 — 문장·근거·출처 표기

배정 46건(critical 0 · major 25 · minor 21). **고침 34 · 부분 12 · 못 고침 0.** '부분'의 남은 몫은 모두 맡은 범위(텍스트 노드·aria-label·alt·title) 밖이다: 장 나누기·태그 요소 추가·태그 자리 이동(구조, PR2/PR7), 차트 안 글자·chart-data 라벨(PR3), `<title>`(PR4), design-standard 문서(PR7).

- 맡은 범위: `presentation/index.html`의 텍스트 노드와 텍스트성 속성만. 클래스·구조·스타일·`<head>`·`<script>`·`data-chart` 안쪽·chart-data는 건드리지 않았다. 예외 한 곳: 22장 헤드라인이 오른쪽 사진 면(x 1,194)과 겹쳐 한 줄로 줄일 수 없어 헤드라인 안에 `<br>` 하나를 넣었다(fit.js가 의도한 줄바꿈으로 세는 표기, 다른 장 헤드라인과 같은 방식).
- 숫자: `check-numbers` unverified [] 유지. 새로 적은 숫자는 출처 연도·범위뿐이고 모두 `research/`·`chart-data.json`에 있는 값이다(McKinsey 범위 2030–2060, Epoch 전망 2.2–2.9배 등). EVD-01(장별 숫자 토큰 보존)도 기준(pr2)과 같다 — 지운 내부 코드의 숫자는 문구로 되살렸다(관계식 R1 → 「관계식 1」, 수업 주차는 꼬리말로).
- 주장 라벨(`.tag`)은 글자 하나도 바꾸지 않았다(EVD-02가 (장, 라벨) 쌍을 기준과 대조). 라벨이 필요한 곳은 본문 글자로 '추정'·'2차'를 덧붙였다.
