# 이상 상태 — 보편 인터페이스 가이드라인 기준

출처: Apple HIG 전문 173쪽(2026-10-16 수집)에서 애플 고유 요소를 뺀 보편 원칙 + AI slop·프론트엔드 크래프트 규칙 + 사용자 확정 사항. 원칙은 [hig-principles.md](hig-principles.md), 규칙은 [rules.md](rules.md).

## 요약

링크를 열면 어떤 기기에서든 1~1.5초 안에 Pretendard로 그려진 표지가 곧 콘텐츠로 보이고, 기기에 맞는 한 줄 조작 안내가 콘텐츠를 가리지 않고 떴다가 사라진다. 키보드·클리커·스와이프·보이는 버튼·개요가 모두 같은 이동으로 이어지고, 연타해도 입력을 잃지 않으며, 처음과 끝에 닿으면 그 사실을 보여 준다. #n 딥링크·hashchange·새로고침·새 탭 복귀가 모두 같은 장을 지킨다. 위치(섹션명 · n / 34)와 틀(헤드라인 시작점·꼬리말·쪽 번호)은 모든 장에서 같은 자리에 있고, 화면 위 컨트롤은 장 내용을 절대 가리지 않으며 발표 중 유휴 시 사라진다. 각 장은 한 가지 역할과 하나의 초점을 갖는다: 결론형 헤드라인(2줄 이하, 쉼표·콜론 없음, ~습니다·명사형) → 근거 시각물 → 숫자 옆 주장 라벨 → 잘리지 않는 출처·기준 연도. 카드는 그룹이라는 뜻이 있을 때만 장당 0~1개 쓰고, 묶음은 여백·정렬·배경 면 전환(18장 방식)으로 만들어 연속 세 장이 같은 면을 쓰지 않는다. 색은 토큰(채도 낮춘 인디고·세이지·따뜻한 스톤)만, 인디고는 장마다 핵심 한 곳, 원색·보라→파랑 그라데이션·유리·글로·진한 그림자 없음, 그라데이션은 같은 계열의 미세한 것만 소수 장에. 모든 글자-바탕 쌍은 실측 4.5:1(큰 글자 3:1), 데이터 마크 3:1, 프로젝터·압축·흑백·색각이상에서도 직접 라벨과 선 모양으로 읽힌다. 글자는 프리셋 9단계·굵기 400/600/700·4px 행간·18px 하한을 지키고 청중 본문은 24px를 목표로 한다. 차트 9개는 같은 문법(차트 위 제목·단위·기간, 강조 1계열, 직접 라벨, 겹침 없는 라벨, 실제 날짜 간격 축, 차트 아래 출처+라벨)과 값을 담은 접근성 설명을 갖고, 숫자는 chart-data.json·분석 출력과 하나도 다르지 않다. 모션은 목적이 있는 것만: 장 전환 250ms 이하, 장 안 등장 1초·차트 빌드 1.5초 이하, overshoot·무한 루프 없음, 재방문 장은 완성 상태, 모션 감소·인쇄·JS 실패·anime 차단에서도 최종 상태. 비현재 장 inert·aria-live 안내·focus-visible·확대 허용으로 보조기기 사용자도 같은 여정을 간다. 외부 요청·추적 없이 자체 호스팅하고, og 미리보기·favicon·color-scheme·theme-color를 갖추며, PDF는 34쪽 최종 상태로 나온다. design-standard에는 장별 역할 표·색 의미 표·컴포넌트 매핑·용어집·모션 목록·예외 목록이 실제 CSS 값과 일치하게 있고, 헌법 감사·token-check·check-numbers·render 보고가 모두 0이며, before/after 34장 렌더를 사람이 직접 보고 장별 체크표로 확인한다. 상충 해소 원칙: 사용자 확정 > 헌법(designsystems.com) > 공통 designing-decks-and-motion 스킬 > 데이터 덱 층 > taste/soft-skill. 예) 인디고 팔레트는 taste의 purple 금지보다 우선(inspect --allow palette-purple), 미세 그라데이션 허용, kicker는 정보가 있을 때만 알약 없이 허용, 한글 자간은 −0.02em보다 좁히지 않음, 영웅 숫자는 비례 숫자·표와 눈금만 tabular, 장 전환 뒤로 가기는 점프에만 pushState.

## 페르소나

### A 채점자 교수
- 맥락: 제출된 공개 URL을 노트북 브라우저 창(1280~1440 폭, 전체 화면 아님)에서 혼자 연다. 발표자 설명이 없어 장 제목·차트 제목·출처·주장 라벨만으로 논증과 데이터분석 계획을 평가한다. 근거 장으로 되돌아가거나 특정 장으로 건너뛰고, 보관용으로 PDF 인쇄를 할 수 있다.
- 목표: 표지에서 주제와 결론 숫자를 바로 파악한다 / 조작법을 따로 묻지 않고 넘기고 건너뛴다 / 수치마다 출처·기준 연도·주장 라벨(기술·추정·2차)을 확인한다 / 원문 링크를 새 탭으로 보고 같은 장으로 돌아온다 / 34쪽 최종 상태 PDF로 저장한다
- 걸림돌: 조작 안내가 없고 개요는 Esc로만 열린다(관례와 반대) / 출처가 text-overflow ellipsis로 잘려 채점 근거가 사라진다 / hashchange를 처리하지 않아 주소창에서 #12로 고쳐도 이동하지 않는다 / R1·β·φ 같은 코드와 기호가 풀이 없이 처음 나온다 / PDF 인쇄 때 beforeprint에 기대는 차트가 빈 상태로 찍힐 수 있다

### B 휴대폰 수강생
- 맥락: 카카오톡이나 LMS로 받은 링크를 세로 휴대폰(375~390 폭)에서 연다. 키보드가 없고 모바일 데이터와 느린 회선을 쓴다.
- 목표: 링크 미리보기 카드로 무엇인지 알고 들어온다 / 스와이프나 탭으로 끝까지 넘긴다 / 글자를 읽을 수 있는 크기로 본다(가로 회전이나 확대) / 데이터 요금 부담 없이 빨리 첫 화면을 본다
- 걸림돌: present.js가 keydown만 받아 1장에서 여정이 끊긴다(치명) / 1920 캔버스가 약 0.2배로 줄어 18px 라벨이 약 3.7px가 된다 / og 메타와 favicon이 0개라 미리보기 카드가 비어 있다 / 2.06MB 글꼴이 font-display block이라 글자 없는 표지가 오래 보인다 / '다시 재생 (R)'처럼 키 표기가 터치 기기에도 보인다

### C 화면 공유 발표자
- 맥락: 화면 공유나 프로젝터로 키보드·클리커(PageDown/PageUp)를 써서 34번 이상 넘기고, 질의응답 때 특정 장으로 뛰어갔다가 돌아온다.
- 목표: 누르는 즉시 정확히 한 장씩 넘어가고 연타해도 입력이 사라지지 않는다 / 공유 화면에 조작 UI가 남지 않는다 / 개요로 특정 장에 뛰어갔다가 뒤로 가기로 돌아온다 / R로 원하는 장의 빌드를 다시 보여 준다
- 걸림돌: 고정 '다시 재생 (R)' 버튼이 늘 떠 있고 쪽 번호와 겹칠 수 있다 / Esc를 '빠져나가기'로 알고 누르면 개요가 열린다 / 장마다 블러 차례 등장이 최대 약 1.5초 반복돼 발표 리듬이 늦어진다 / 개요에 현재 장 표시·닫기 버튼이 없다

### D 원격 청중
- 맥락: 압축된 720p 화면 공유 영상이나 강의실 프로젝터로 멀리서 본다. 대비가 떨어지고 색이 뭉개진다.
- 목표: 헤드라인과 핵심 숫자만으로 장의 주장을 따라간다 / 발표자가 말하는 '17장'을 쪽 번호로 찾는다 / 차트에서 어느 계열이 강조인지 색 없이도 안다
- 걸림돌: 14·16px 프리셋과 18px 라벨이 720p에서 12px 이하가 된다 / 옅은 회색(#cac7c2) 차트 마크와 연세이지 면이 투사에서 사라진다 / 색만으로 구분한 계열과 10장 '2047'처럼 선과 겹친 값 라벨

### E 비판적 데이터 독자
- 맥락: 수업 동료나 조교로서 숫자가 원자료와 맞는지, 추정과 실측이 구분되는지, 인과를 과장하지 않는지를 따진다.
- 목표: 숫자마다 출처·기준일·n·기간을 확인한다 / 추정값에 범위와 '추정' 라벨이 붙어 있는지 본다 / 한계와 가정이 어디에 있는지 찾는다 / 차트 축이 실제 날짜 간격·0 기준인지 확인한다
- 걸림돌: 출처 뒷부분이 말줄임으로 잘린다 / 차트 aria-label이 제목뿐이라 값을 텍스트로 얻을 수 없다 / 'r = −0.97 n=3' 같은 수치 옆 한계 설명이 있는지 불분명하다 / 같은 데이터를 보여 주는 차트 쌍(7↔22장, 17↔25·26장)의 표기가 일관된지 불확실하다

### F 접근성 필요 사용자
- 맥락: 저시력(확대 필요), 색각이상, 모션 민감, 스크린리더 사용자. 시스템 설정(prefers-reduced-motion, 확대, 고대비)을 켜고 본다.
- 목표: 핀치나 브라우저 확대로 글자를 키운다 / 모션 감소 설정에서 움직임 없이 최종 상태를 본다 / 스크린리더로 현재 장 번호·제목·차트 핵심 값을 듣는다 / 키보드만으로 모든 컨트롤과 개요에 닿는다
- 걸림돌: fit()이 브라우저 확대를 상쇄한다 / 표지 5500ms setInterval 무한 교차 페이드와 블러 등장 / 비현재 장이 접근성 트리와 Tab 순서에 남을 수 있다 / 큰 숫자가 .t-digit span으로 쪼개져 '1, 0, 5'로 끊겨 읽힌다 / focus-visible 스타일이 없다
