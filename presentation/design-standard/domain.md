# 헌법 적용 기록

헌법은 designsystems.com Getting Started다(공통 덱 스킬 `references/constitution.md`, 2026-10-16 읽음). 이 덱에 적용한 조항과 그 결과를 적는다.

| 조항 | 이 덱에서 한 것 |
| --- | --- |
| 제1조 감사에서 시작 | `constitution_audit.py`로 글자 크기 20 · 굵기 5 · 위반 93을 세고, 비슷한 값을 합쳐 9 · 3 · 0으로 줄였다. 한 번만 쓰인 값(92 · 84 · 30 · 26 · 21 · 19 · 17 · 15px 등)은 가장 가까운 프리셋으로 흡수 |
| 제2조 공간 | 모든 간격을 8의 배수로. 계단 문장 들여쓰기 110 · 220 · 330 · 440 → 96 · 192 · 288 · 384 |
| 제3조 그리드 | 12열, 거터 48을 열 · 같은 열 카드 · 타일 · 숫자 줄에 같은 값으로 |
| 제4조 타이포 | 본문 20/32에서 출발한 프리셋 15개(크기 9단계), 굵기 400 · 600 · 700, 행간 4의 배수 |
| 제5조 색 | 원색 두 개를 채도를 낮춘 인디고 · 세이지 단계로, 중립을 스톤 하나로 합치고 토큰 밖 색 리터럴 0. 대비 쌍 표는 [color.md](color.md) |
| 제6조 콘텐츠 | 용어집과 문구 모양([components.md](components.md#용어집)). 지어낸 비유 · 압축어를 잰 대상의 이름으로 |
| 제7조 모션 | 시간은 transitions.dev 토큰(40 · 80 · 150 · 250 · 350 · 400 · 500ms), 이징 셋(들어오고 나갈 때 smooth-out `0.22, 1, 0.36, 1` · 표지 사진 교차 페이드 soft `0.32, 0.72, 0, 1` · 숫자 팝인 `0.34, 1.45, 0.64, 1`). 전환 중 수십 장이 함께 움직이지 않게 개요 열고 닫기는 전환 없이 |
| 제8조 아이콘 · 동심 | 모서리 32 · 24 · 16. 인물 카드 · 영상 캡션의 안쪽 모서리를 바깥 − 여백으로 맞췄다 |
| 제9조 확인 | 헌법 감사 0 · 렌더 이상 0 · 숫자 167개 대조 · 34장 컨택트시트 |
