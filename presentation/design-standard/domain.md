# 헌법 · 시스템 규칙 적용 기록

헌법은 designsystems.com Getting Started(공통 덱 스킬 `references/constitution.md`)다. 제품 디자인 시스템이 이미 그 원칙(HIG + designsystems.com Getting Started 종합, 규칙 1,034개)으로 만들어져 있어서, 이 덱은 **시스템 값을 그대로 쓰는 것으로** 대부분의 조항을 지킨다. 덱에서 따로 결정한 것만 적는다.

| 조항 | 이 덱에서 한 것 |
| --- | --- |
| 제1조 감사에서 시작 | 옛 디자인(soft-skill 「Soft Structuralism」 · 스톤 바탕 · 인디고/세이지 · 이중 테두리 카드 · 부분 글꼴 · 장식 사진 · 147조건 시각 QA)을 전부 걷어 내고 시스템 하나로 바꿨다. 잔재 목록과 처리는 저장소 README 「디자인 정리」 |
| 제2조 공간 | 시스템 간격 단계(4 · 8 · 16 · 24 · 32 · 40 · 48 · 64)만. 홀수 · 단계 밖 값 0(시스템 `check.mjs` 3번, 헌법 감사) |
| 제3조 그리드 | 12열, 열 사이 = 시스템 `layout-gutter`(24). 고정 레이아웃 캔버스 1280 × 720(rem) |
| 제4조 타이포 | 시스템 글자 역할 8개(26 · 22 · 18 · 15 · 15 강 · 13 · 13 강 · 12) + 덱 큰 글자 2개(히어로 display 44/52 · 큰 숫자 figure 36/44 — 시스템 presets.md:143이 덱 지침에 맡긴 자리). 굵기 400 · 600 · 700 셋 그대로, 행간 4의 배수, 위계는 크기로 먼저(묶음 · 차트 제목 18 > 항목 제목 15). [typography.md](typography.md) |
| 제5조 색 | 시스템 의미 토큰만(16진수 · 원시 척도 0). 반복되는 색 쌍: 주장 라벨(인디고 = 자료 · 출처가 있는 값, 보라 = 이 발표가 계산 · 가정한 값 — 글자가 뜻을 말한다), 차트 계열은 대상마다 고정(기준 · AGI · 사무직 = 파랑, 빠름 · 자동화 · 전문직 = 갈색, 신중 · 맥락 = 중립), 절 표시 파랑 · 노랑 번갈아(뜻 없음). 대비 · 표는 [color.md](color.md) |
| 제6조 콘텐츠 | 해요체 하나 · 금지 표현 목록 · 국립국어원 표기(시스템 WR 장). 문장 모양과 용어집은 [components.md](components.md#7-화면-글) |
| 제7조 모션 | 시스템 시간 4단계(140 · 220 · 320 · 440ms) · 곡선 2개(productive · expressive). 기능 모션만(정본 MO-01 · 02): 덱에 남은 효과는 이름 있는 덱 패턴 둘 — 장 사이 이동(motion-page-slide-in · -fade-out)과 조작부 쉬는 모양 전환(motion-controls-fade-move — 버튼 면 · 테두리 · 글자색, 투명도 없음). 장 안 차례 등장 · 차트 단계는 2026. 10. 21. 없앴다. 들어옴 = 표현용 · 나감 = 기능용 · 투명도만. 키보드 입력은 모두 바로(MO-03), 동작 줄이기는 투명도만 |
| 제8조 아이콘 | Lucide 1.50.0 스프라이트 하나(16 · 20 · 24, 선 2). 쓰는 곳: 조작부만 — 전체 장 보기(squares-grid) · 처음으로(house) · 이전 · 다음(chevron) · 닫기(xmark). 뜻이 맞는 그림이 없는 동작(다시 재생 · 전체 화면)은 글자 버튼(IC-03). 차트 범례의 삼각형은 글자 기호가 아니라 그린 모양 |
| 제9조 확인 | 렌더 PNG를 직접 봄 · `fit.js` issues · 헌법 감사 · 시스템 `check.mjs` · 숫자 대조 · 발표 이동 검사([README](README.md#검사와-예외)) |
