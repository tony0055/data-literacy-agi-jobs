# 컴포넌트와 문구

값의 기준은 `../src/deck.css`(공통 부품) · `../src/slides.css`(이 덱 부품)다.

## 뼈대

```
.slide(.dark · .nohead · .bleed · .cover)
  .head  → .kicker(알약 라벨) / .headline / .lead
  .body  → .grid > .cN  또는 한 부품
  .sowe  → b(라벨) + 한 문장
  .foot  → .source + .pg
```

## 부품

| 부품 | 클래스 | 쓰임 |
| --- | --- | --- |
| 카드 | `.card` (+ `.accent` `.sage` `.ink` `.soft`) | 같은 그룹이라는 뜻이 있을 때만. 강조 카드는 한 장에 하나 |

## 차트

| 부품 | 클래스 | 규칙 |
| --- | --- | --- |
| 묶음 | `.chart` | 부제 → SVG → 출처 순 |

| 부제 | `.chart-sub` | 무엇을 잰 축인지 |

## 주장 라벨

`.tag`(기술 · 2차 · 직접 · n=3 등)와 `.tag.est`(추정). 미관 때문에 지우지 않는다. '인과'는 이 덱에서 쓰지 않는다.

## 용어집

| 쓸 말 | 쓰지 않을 말 | 이유 |
| --- | --- | --- |
| AI가 맡을 수 있는 업무 크기(METR 50% 시간지평) | AI가 혼자 끝내는 일의 길이 | 무엇을 재는지 드러낸다. 처음 한 번 풀어 쓴다 |
| 두 배가 되는 데 걸린 기간 | 배가 간격 · 1배가당 | 압축어를 피한다 |
| AGI 예상 연도 · 모든 직업 자동화 예상 연도 | AI 시계 · 일자리 시계 | 덱에서 지은 비유를 쓰지 않는다 |
| 대체 압력 | 대체 · 실업 | 모형 값(고위험 일자리 × 사람이 빠지는 비율 0.5)이고 실제 해고 수가 아니다 |
| 신입 채용 | 입구 | 같은 이유 |
| 로봇 학습 데이터 | 물리 세계 데이터 · 몸 | 같은 이유 |

## 문구 모양

- 킥커: 명사구, 「구역 · 관계식」. 제목: 한 문장, 마침표 · 쉼표 · 콜론 없음.
- 본문: '~습니다'와 명사형을 섞는다.
- 결론 띠 라벨: 「그래서」 「읽는 법」 「모형에서는」 「지금 따져 볼 것」처럼 장의 역할에 맞춘다.
