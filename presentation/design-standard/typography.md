# 타이포그래피

값의 기준은 `../src/tokens.css`의 `--t-*` 프리셋이다. 컴포넌트는 `font: var(--t-이름) var(--font)`로 프리셋만 부른다(헌법 제4조).

## 글꼴

Pretendard Variable 한 가족(`../assets/fonts/PretendardVariable.woff2`, SIL OFL 1.1 — `Pretendard-LICENSE.txt`). 제목 · 본문 · 숫자 모두 같은 가족이고, 위계는 굵기보다 크기로 만든다.

## 프리셋

본문 20/32에서 출발해 약 1.25배씩 올렸다. 크기 아홉 단계(14 · 16 · 20 · 24 · 32 · 48 · 64 · 80 · 96), 굵기 세 단계(400 · 600 · 700), 행간은 모두 4의 배수다.

| 프리셋 | 굵기 크기/행간 | 쓰는 곳 |
| --- | --- | --- |
| `--t-small` | 400 14/20 | 차트 출처 |
| `--t-label` | 600 14/20 | 킥커 · 태그 · 표 머리 · 표지 머리줄 |
| `--t-caption` · `-strong` | 400 · 600 16/24 | 꼬리말 · 범례 · 차트 부제 · 보조 설명 |
| `--t-body` · `-strong` | 400 · 600 20/32 | 본문 · 표 칸 · 결론 띠 · 알약 |
| `--t-lead` | 400 24/36 | 표지 설명 |
| `--t-title` | 700 24/32 | 카드 · 차트 제목, 숫자 단위 |
| `--t-h3` | 700 32/40 | 직급 표 안 연도 |
| `--t-headline` | 700 48/64 | 장 제목(두 줄까지, 줄은 `<br>`로 직접) |
| `--t-poster` | 700 48/56 | 직업군 안내판 이름 |
| `--t-number` | 700 64/64 | 카드 숫자 |
| `--t-statement` | 700 64/80 | 2장 계단 문장 |
| `--t-display` | 700 80/88 | 표지 제목 |
| `--t-hero` | 700 96/96 | 결론 타일 · 사진 장 숫자 |

차트 SVG 글자는 20px(본문 크기)로, 저장소 데이터 덱 규칙(축 눈금 · 직접 라벨 18px 이상)을 지킨다. 칸에 맞춰 차트가 줄어들어도 실제 글자가 18px 아래로 내려가면 `fit.js`가 실패로 잡는다.

## 한글

`word-break: keep-all`, 숫자는 `tabular-nums`. 제목 · 인용 · 차트 제목에 쉼표 · 콜론을 쓰지 않고 연결 어미나 줄바꿈으로 나눈다.
