# 레이아웃

값의 기준은 `../src/tokens.css` + `../src/deck.css`다(헌법 제2 · 3조: 8 선형 단계, 거터에도 같은 단계, 내용 우선).

## 캔버스와 여백

| 값 | 크기 |
| --- | --- |
| 캔버스 | 1920 × 1080 (고정 레이아웃) |
| 좌우 · 위 · 아래 | 160 · 112 · 64 |
| 12열 거터 · 같은 열 카드 사이 | 48 · 48 |
| 머리 → 본문 | 64(제목 두 줄이면 48) |
| 본문 → 결론 띠 · 결론 → 꼬리말 | 48 · 32 |
| 카드 · 차트 · 수식 안쪽 | 48 |
| 결론 띠 안쪽 | 24 × 32 |
| 반증 띠 사이 · 안쪽 | 16 · 24 × 40 |

간격은 8의 배수만 쓴다. 4와 12는 아이콘 · 작은 글 덩어리의 반 단계로만 쓴다.

## 내용 우선

- 카드는 내용만큼 차지하고 본문 칸 세로 가운데에 둔다. 빈칸을 채우려고 늘리지 않는다.
- 본문 칸이 모자라면 차트가 비율째 줄어든다. 줄어든 글자가 18px 아래면 `data-h`로 세로 길이를 칸에 맞춘다(13 · 17 · 24장).
- 한 장에 차트 하나 또는 카드 두세 개. 넘치면 장을 나눈다.

## 모서리와 깊이

| 토큰 | 값 | 쓰는 곳 |
| --- | --- | --- |
| `--r-shell` | 32 | 큰 껍데기(타일 · 사진 · 인물 카드 · 안내판) |
| `--r-core` | 24 | 카드 · 차트 · 결론 띠, 껍데기 안쪽 요소(32 − 여백 8) |
| `--r-inner` | 16 | 안쪽 블록 |
| `--r-pill` | 999 | 알약 · 태그 |
| `--bezel` | 4px 흰 링 + 1px 선 + `--sh-float` | 이중 테두리 카드(링은 카드 모서리와 동심) |

겹친 모양의 안쪽 반지름은 바깥 반지름에서 안쪽 여백을 뺀 값이다(헌법 제8조).
